## 👤 自己紹介

2003年埼玉県さいたま市生まれ。屋号**「エノキ電気」**代表。
**某企業にてCTO（最高技術責任者）**を務める傍ら、**ボカロP（ときえのき / 刻夏P）**としての音楽活動、個人開発者としてのWebサービス・スマホアプリ・自作Linux OS開発、さらには弱電工作やバイクの自力エンジン載せ替えまで、多岐にわたる創作・開発を行っています。

「趣味で突き詰めていたら仕事になっていた」タイプ。気になるものはソフトウェアからハードウェア、インフラ、モビリティまで何でも自分で作って動かすマルチクリエイターです。

## 🎵 音楽活動

**ボカロP「ときえのき（刻夏P）」**として2017年よりVOCALOID楽曲の制作を開始。
作詞・作曲・編曲からCD制作、サブスク配信まで幅広く手掛けています。

|                                              🎸 音楽チャンネル                                              |                                      ⚡ 電気チャンネル（技術・工作系）                                      |
| :---------------------------------------------------------------------------------------------------------: | :---------------------------------------------------------------------------------------------------------: |
| [![YouTube音楽](https://img.youtube.com/vi/MnpR0V_jJj8/0.jpg)](https://www.youtube.com/watch?v=MnpR0V_jJj8) | [![YouTube電気](https://img.youtube.com/vi/jTjxiQ4HtVw/0.jpg)](https://www.youtube.com/watch?v=jTjxiQ4HtVw) |

- 🎹 **サブスク配信**: Spotify、Apple Music、LINE MUSIC等でオリジナル楽曲を全世界配信
- 🎤 **カラオケ配信**: 全国の**JOYSOUND**設置店舗にてオリジナル楽曲がカラオケ歌唱可能
- 💿 **同人即売会**: コミックマーケット（C105）サークル参加にてオリジナルCDを頒布
- 🎮 **ゲームMOD**: Steam Workshop版『Cities: Skylines』向けに楽曲MOD [CS_Music](https://github.com/jikantoki/CS_Music) を提供
- 🕹️ **自作音ゲー**: 音ゲーアプリも自作 → [livehouse](https://github.com/jikantoki/livehouse)
